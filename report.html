Abstract
Security Operations Centers (SOCs) and defense cybersecurity teams must review large volumes of threat reports and alerts. Manual triage is slow, inconsistent, and does not scale. This project presents an AI-powered Cyber Threat Intelligence (CTI) Dashboard that automates initial triage using NLP and Machine Learning: cleaning/normalization, IOC extraction (IP, domains, hashes, CVEs), keyword extraction, TF-IDF-based embeddings, and extractive summarization. Two supervised models predict category and severity; outputs are combined with asset criticality and report recency in an explainable Priority Scoring formula that ranks incidents for analyst review.

Priority Scoring (Explainable)
The priority score is computed as a weighted, auditable formula:
priority_score = 100 × (w1·severity_component + w2·category_risk + w3·asset_criticality + w4·recency)
where recency uses exponential decay (half-life ~7 days by default). The score is then bucketed into P1–P4 tiers.
